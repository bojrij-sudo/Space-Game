# Space Strategy Game

Пошаговая космическая стратегия в браузере.

## Как запустить
Игра уже развёрнута на GitHub Pages: [bojrij-sudo.github.io/Space-Game/](https://bojrij-sudo.github.io/Space-Game/)

## Локально
1. Клонируйте репозиторий.
2. Откройте `index.html` в браузере.

## Механика
- Поле 100×100 клеток.
- Планеты дают ресурсы.
- Солнце наносит урон кораблям в соседних клетках.
- Лимит ходов: 30.
