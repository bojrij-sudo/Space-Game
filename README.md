# Space Strategy Game
Пошаговая космическая стратегия: колонизация планет, экономика, флот и дипломатия.

## Правила
- Доска 100×100, Солнце в центре (непроходимо, зона урона).
- Планеты дают слоты под здания; газовые гиганты — только водородные станции.
- Фазы хода: доход → стройка → движение → бой → проверка колонизации/поражения.
- Победа: последний выживший или максимум стоимости по истечении 30 ходов.

## Стек

- Node.js
