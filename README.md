# Космическая стратегия

Пошаговая стратегия на шахматной доске 13×13. Солнце в центре непроходимо
и выжигает корабли рядом (−10 HP). Цель — остаться последней цивилизацией
или набрать больше очков за 30 ходов.

## Запуск

    python main.py --bots 1        # игра против бота
    python main.py --bots 3        # против трёх ботов
    python main.py --botgame 2     # бьют боты, вы наблюдаете
    python main.py --turns 50      # свой лимит ходов

## Структура

- `config.py` — весь баланс: планеты, цены, характеристики. Правьте числа здесь.
- `models.py` — структуры данных.
- `engine.py` — правила: доход, стройка, движение, бой, колонизация, дипломатия.
- `ai.py` — простой бот (экономика → флот → война и захват).
- `main.py` — консольный интерфейс и игровой цикл.

## Кратко о правилах

- Планеты: скалистые (шахты и генераторы), газовые гиганты (только водородные
  станции, зато много слотов и дешёвая энергия), ледяные (−25% добычи).
- Колонизация: корабль стоит на планете до начала вашего следующего хода —
  планета ваша. Чужая планета требует войны и пережить ход под огнём.
- Юниты двигаются как фигуры: истребитель — король, рейдер — конь,
  крейсер — ферзь до 2 клеток. Атака: истребитель вплотную, рейдер и крейсер
  по прямой (крейсер до 3, рейдер до 5), Солнце блокирует луч.
- Дипломатия: нейтралитет, война, союз. Обмен ресурсами — 1 сделка
  с цивилизацией за ход. Война с бывшим союзником: −10 энергии за планету.
